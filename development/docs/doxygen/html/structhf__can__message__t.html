Detailed Description

Platform-agnostic CAN / CAN FD message (BaseCan v2).

The payload buffer is FD-sized (64 bytes) and the length is a byte count, never a DLC code:

  • dlc holds the payload length in bytes: 0..8 for classic frames, 0..8, 12, 16, 20, 24, 32, 48 or 64 for FD frames. The name is kept for source compatibility (for classic frames the byte count and the DLC code are the same number). Use GetLength() / SetLength() in new code, and GetDlcCode() / SetDlcCode() when a controller needs the 4-bit wire code.
  • SetLength() / SetDLC() reject lengths the frame kind cannot carry (above 8 on a classic frame, or an FD length without a DLC code), so data can never be over-read or over-written through them.
  • Flags: is_extended, is_rtr, is_canfd, is_brs, is_esi, also available packed as hf_can_flag bits via GetFlags() / SetFlags().
  • timestamp_us is the RX timestamp captured by the driver (ISR side). It is ignored on transmit.

Code that writes dlc directly must keep it valid for the frame kind; drivers check it with Validate() before touching data.

ToFrame() / FromFrame() convert to and from any frame struct with the members id, len, flags, data[64] and ts_us (the layout of vortex::contracts::CanFrame). A frame round trip (frame -> message -> frame) is lossless.

Copy into a frame with members id, len, flags, data[64], ts_us.

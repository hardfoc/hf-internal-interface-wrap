Detailed Description

Soft-CS SPI slave on a shared StmSpiBus.

Owns one GPIO chip-select and a per-device SPI mode (hf_spi_device_config_t::mode). Each Transfer:

  1. Takes StmSpiBusLock (RTOS mutex — peers wait),
  2. Parks all soft-CS on the bus idle-high,
  3. Applies this device's CPOL/CPHA (SPE toggle only with every CS high),
  4. Flushes the RX FIFO,
  5. Scopes only this CS with SoftChipSelectGuard,
  6. Releases the bus lock.

Mixed Mode 0/1/3 slaves may share one CubeMX SPI peripheral. Chip handlers and external drivers must not poke CS — only Transfer / TransferChain.

Note
CS low during a Mode1 (TLE) frame is expected. CS must be high for every other slave while Mode0/1/3 SPE/CPOL is being rewritten.

N soft-CS frames under one bus lock (CS still toggles per frame).

Holds StmSpiBusLock across the chain so Mode0/1/3 peers cannot interleave mid-pipeline (e.g. TLE command + dummy). Each frame uses its own SoftChipSelectGuard — matching datasheets that require CSN rise between 32-bit accesses.

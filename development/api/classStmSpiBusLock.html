Detailed Description

RAII exclusive ownership of one StmSpiBus (RTOS mutex).

Higher-level threads may block here with a timeout — that is intentional. Do not disable interrupts across SPI frames; serialize with this lock. Direct HAL probes / wire-proof paths must take the same lock.

Enumeration Type Documentation

◆ Status

enum class hf::Status : std::uint8_t
strong

Outcome of an operation, coarse enough to act on.

Enumerator
Ok 

Success.

NotInitialized 

The object has not been (successfully) initialised.

InvalidArgument 

A parameter is out of range; nothing was done.

Busy 

The resource is in use; retrying later can succeed.

Timeout 

A wait expired.

Bus 

A transfer failed: NACK, CRC, framing, arbitration, transport error.

NotFound 

The device or resource is absent or answered with the wrong identity.

Fault 

The device reported a fault, or a check of its state failed.

Unsupported 

The operation is not available on this chip, board or build.

DependencyNotReady 

Something this call needs (a bus, a manager, a handler) failed to start.

NoMemory 

A fixed-capacity pool or table is full.

Unknown 

Anything that maps to none of the above.

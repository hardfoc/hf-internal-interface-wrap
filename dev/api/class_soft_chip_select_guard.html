Detailed Description

template<typename AssertFn, typename DeassertFn>
class SoftChipSelectGuard< AssertFn, DeassertFn >

RAII soft-CS: runs assert_fn on construction and deassert_fn on destruction (including early return / error paths).

DeassertFnCallable void()

Typical STM32 soft-CS device usage (inside a bus lock):

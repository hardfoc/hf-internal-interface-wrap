◆ combined_read

bool hf_i2c_device_config_t::combined_read

Register reads (WriteRead with a 1–2 byte register address) use the I2C combined format: START, address+W, register, repeated START, address+R, data, STOP. Some targets (NXP PF1550) reject the register write when it ends in STOP and NACK the following read. Off by default: the split Transmit/STOP/Receive framing stays for parts proven on it.

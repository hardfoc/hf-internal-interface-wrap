Detailed Description

Version macros for the hf-internal-interface-wrap submodule.

Manually-curated semantic version. Bump on releases together with the matching git tag in this repo. Consumers (e.g. the parent app's version manifest) pick this up via __has_include of iiwrap_version.h.

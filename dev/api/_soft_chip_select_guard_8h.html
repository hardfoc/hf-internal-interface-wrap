Detailed Description

RAII soft chip-select (assert on construct, deassert on destroy).

Use around a single SPI frame (or an intentional multi-byte burst that must stay under one CS assertion). Pair with a bus mutex held for the whole mode + FIFO + transfer window — this guard only owns the CS pin edges.

Note
Does not replace bus locking. Callers must already own the SPI bus mutex so peers cannot change CPOL/CPHA or steal the peripheral.

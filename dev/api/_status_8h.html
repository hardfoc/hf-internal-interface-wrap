Detailed Description

hf::Status and hf::Result<T>: the one error model of every layer above the drivers.

Each layer keeps its own detailed codes (a driver's Error, an interface's hf_*_err_t) and maps them once onto hf::Status; the original code travels along as detail. Code branches on status, never on detail. The values and their meaning are defined in the HardFOC standard (standards/errors.md in hardfoc/.github) and are never renumbered.

No dependencies, no heap, C++17. The Base* headers map their hf_*_err_t with hf::ToStatus().

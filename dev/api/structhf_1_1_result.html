Detailed Description

template<typename T>
struct hf::Result< T >

A value and the status of the call that produced it.

value is meaningful only when ok(); otherwise it holds T{}. detail is the originating layer's own code (a driver Error, an hf_*_err_t, a manager code), 0 if none, for logs only. An ignored Result is a compiler warning.

hf::Result<float> r = handler.ReadPressurePa();
if (!r.ok()) { return r.status; }
use(r.value);

Detailed Description

ESP32-family implementation of the high-resolution monotonic time source consumed via HfTime.h.

Backed by esp_timer_get_time(), a 64-bit µs counter driven by a dedicated hardware timer that ESP-IDF starts before app_main. The counter is monotonic for >292 000 years so wrap is not a concern.

Header-only inline implementation: every call lowers to a single esp_timer_get_time call with no extra frames so it is safe inside hot-path measurement loops (valve self-test sweeps, parallel-stress sampler, ramp settling detectors).

Do not include this file directly from middleware/app code — go through HfTime.h so MCU dispatch stays in one place.

Detailed Description

One MCU SPI peripheral + its soft-CS device collection.

Applies per-device SPI mode on transfer so soft-CS multi-slave buses (e.g. MAX Mode 0 + TLE Mode 1) work despite a single CubeMX SPI Init block. Transfers are serialized with PlatformMutex via StmSpiBusLock. Opt-in bench register-poke paths must take the same lock.

Note
Soft-CS multi-slave contract (this MCU binding):
  • Stage short payloads through D1 AXI when the caller buffer may sit in external FMC SDRAM (byte-access hazard class shared with StmI2c).
  • Flush RX FIFO + clear EOT/TXTF before each soft-CS frame (and after HAL errors so the next peer does not see stale bytes).
  • CS is SoftChipSelectGuard-scoped per frame; software GPIO already exceeds datasheet tCSS — short settle only.
  • Clear HW NSS-pulse (SSOM) so multi-byte transfers are one continuous stream under the asserted CS line.

Apply mode (CPOL/CPHA), midi_cycles (CFG2.MIDI) and clock_speed_hz (CFG1.MBR) if they differ from the last applied values. Safe to call with SPE briefly cleared.

Parameters
midi_cyclesSCK idle cycles between data frames (0–15). See hf_spi_device_config_t::inter_data_idle_cycles for why this is per-device: FIFO-serviced slaves want the pause, shift-register slaves (TLE92466ED) need a continuous 32-bit stream.
clock_speed_hzTarget SCK in Hz; 0 keeps whatever prescaler is already programmed (CubeMX default). See hf_spi_device_config_t::clock_speed_hz.
reconfiguredOptional out-flag: true when CFG1/CFG2 were actually rewritten. Callers use this to decide whether the post-mode CPOL settle is needed — an unchanged peripheral cannot have glitched SCK, so the settle is pure WCET on a same-device repeat frame.
Note
Caller must hold StmSpiBusLock and have every soft-CS idle (see IdleAllChipSelects) — SPE toggle must not clock a selected slave.

◆ ProbeMisoLine()

hf_u8_t StmSpiBus::ProbeMisoLine ( void * miso_port,
hf_u8_t miso_pin_pos,
const BaseSpi * device )
noexcept

Bring-up probe of the shared MISO/SDO net — no scope required.

Retargets miso_port bit miso_pin_pos to a plain input, samples it with the internal pull-up and then the pull-down — first with every soft-CS idle, then with only device selected — and restores the original MODER/PUPDR. A slave that drives SDO overpowers the ~40 kΩ internal pull; a high-Z net simply follows it.

Returns
0 if the probe could not run, otherwise bit7 plus: bit0 = CS idle + pull-up reads HIGH, bit1 = CS idle + pull-down reads HIGH, bit2 = device selected + pull-up reads HIGH, bit3 = device selected + pull-down reads HIGH.

Decode: 0x81 idle high-Z and driven LOW when selected — slave is alive and answering zeros. 0x85 high-Z even when selected — slave never drives SDO (unpowered, held in reset, or MISO not landed). 0x80 held LOW with all CS high — short to GND or a peer driving the shared net.

Note
Takes StmSpiBusLock internally; do not call while holding it.

◆ kScratchBytes

constexpr hf_u16_t StmSpiBus::kScratchBytes = 32
staticconstexpr

Per-bus internal-SRAM staging for short transfers. Must only be touched under StmSpiBusLock. A single process-wide scratch raced when two buses transferred concurrently (SensorAcquisition ADS pump vs actuator SPI2) and spliced peer bytes into TMC9660 TMCL frames.

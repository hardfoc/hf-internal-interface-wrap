# Internal Interface Wrap API reference {#mainpage}

The classes, members and types of the HardFOC peripheral interfaces and their platform implementations,
generated from the headers.

Start with the interfaces: BaseGpio, BaseI2c, BaseSpi, BaseCan, BaseAdc, BaseUart, BasePwm, BaseNvs and
BasePeriodicTimer. The ESP32 implementations are the classes whose names start with Esp (EspGpio, EspCan,
EspSpiDevice, ...), the STM32 ones those that start with Stm. Shared types are in HardwareTypes.h.

The guides, with examples that compile, are on the documentation site: <a href="../">Internal Interface Wrap
documentation</a>.
